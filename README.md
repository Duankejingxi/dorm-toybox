## 本地运行

```bash
# 任选一种：
python3 -m http.server 8000
# 然后打开 http://localhost:8000
```

也可以直接双击 `index.html` 打开（全部功能可用，运势和番茄计数存在浏览器本地）。

## 部署到 GitHub Pages

1. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`。
2. 保存后等 1 分钟，访问 `https://<你的用户名>.github.io/dorm-toybox/`。
3. 发到宿舍群 / 朋友圈就能玩。

## 改文案、加玩具

- 改题库、改签文、改转盘默认选项：改 `data.js`。
- 改逻辑：改 `toys.js`。
- 加新玩具：在 `data.js` 的 `TOYS` 里加一项，在 `index.html` 里加一个 `<section class="panel toy">`，在 `toys.js` 里接逻辑——照着现有的抄就行。

## 为什么是“玩具盒”而不是一个大应用

小工具就该小：每个玩具一个文件里几十行逻辑，不依赖任何真实数据（不像“今天吃什么”得先有一份真实店单），所以永远不会因为“数据不准”翻车。坏了一个玩具，其他十三个照样能玩；想加第十五个，复制粘贴就行。

## 技术

- `index.html` — 结构 + 四十六个玩具的分区
- `styles.css` — 深底 + 金粉闪耀风
- `data.js` — 玩具列表、转盘默认选项、真心话 / 大冒险题库、运势签文、老虎机图案、数独备用题、拼豆色板
- `frog-data.js` — 奶蛙表情包第 1 批（用户给的 8 张，内嵌 base64；后续批次 frog-data-2/3/4/5.js，各 30 张）
- `toys.js` — 每个玩具几十行逻辑，数独带生成器 + 求解器
