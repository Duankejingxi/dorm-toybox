# 宿舍玩具盒 · 打开就能玩

> 六个小玩意，宿舍夜话、社团破冰、小组抽人、专注学习都够用。
> 纯前端、零后端、零依赖、零真实数据——打开就能玩，不用下载，不用注册。

## 玩具清单

| 玩具 | 玩法 | 适合 |
| --- | --- | --- |
| 🎡 命运大转盘 | 写 8 个以内的选项，Canvas 转盘转出一个 | 去哪玩、谁请客、晚上干什么 |
| 🃏 真心话大冒险 | 真心话 24 张 / 大冒险 24 张，抽完自动洗牌 | 宿舍夜话、社团破冰 |
| 🎲 骰子硬币 | 扔 1–3 颗骰子，抛硬币定胜负 | 谁先洗碗、谁去买水、谁当鬼 |
| 🍀 今日运势 | 一天抽一签，大吉到末吉，纯属娱乐 | 每天一次的仪式感 |
| 📋 随机点名 | 粘贴名字抽一个，可选“抽过的不再重复” | 社团点名、小组抽人、谁来讲 PPT |
| 🍅 番茄钟 | 25 分钟倒计时，完成后记一个番茄 | 写作业、背单词、改 PPT |
| 👥 随机分组 | 粘贴名字，分成 2–5 组，每组自动指定队长 | 社团分组、宿舍对抗赛 |
| ⚡ 反应测试 | 等绿点按，测手速，记最好成绩 | 课间比手速、开黑前热身 |

## 本地运行

```bash
# 任选一种：
python3 -m http.server 8000
# 然后打开 http://localhost:8000
```

也可以直接双击 `index.html` 打开（全部功能可用，运势和番茄计数存在浏览器本地）。

## 部署到 GitHub Pages

1. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`。
2. 保存后等 1 分钟，访问 `https://<你的用户名>.github.io/dorm-toybox/`。
3. 发到宿舍群 / 朋友圈就能玩。

## 改文案、加玩具

- 改题库、改签文、改转盘默认选项：改 `data.js`。
- 改逻辑：改 `toys.js`。
- 加新玩具：在 `data.js` 的 `TOYS` 里加一项，在 `index.html` 里加一个 `<section class="panel toy">`，在 `toys.js` 里接逻辑——照着现有的抄就行。

## 为什么是“玩具盒”而不是一个大应用

小工具就该小：每个玩具一个文件里几十行逻辑，不依赖任何真实数据（不像“今天吃什么”得先有一份真实店单），所以永远不会因为“数据不准”翻车。坏了一个玩具，其他五个照样能玩；想加第七个，复制粘贴就行。

## 技术

- `index.html` — 结构 + 六个玩具的分区
- `styles.css` — 深底 + 金粉闪耀风
- `data.js` — 玩具列表、转盘默认选项、真心话 / 大冒险题库、运势签文
- `toys.js` — 转盘 Canvas、抽卡、骰子硬币、运势、点名、番茄钟
